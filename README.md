# 海斗助手

面向微信内置浏览器的《英雄联盟》端游“海克斯大乱斗”手机决策工具。

当前开发版本：`v0.2.0`（补丁 `16.16.1 / 26.16`）

## 功能

- 173 位英雄的官方简体中文目录、头像与原画
- 国服与全球统计分开展示；缺失值不推测
- 记录已选强化，计算下一张强化的 0–100 匹配分
- 录入本轮三选一并比较
- 根据英雄与强化联动调整装备顺序
- 本机收藏、对局状态持久化与微信系统分享
- 每个数据区均可查看来源、补丁、样本与更新时间

## 数据口径

- 英雄与装备目录、图标：Riot Data Dragon `16.16.1`
- 英雄强度（全球）：ARAM Mayhem `26.16`
- 英雄强度（国服）：ARAMGG 可核验公开样本
- 强化图标：CommunityDragon `16.16`

强化推荐显示“匹配分”，不是强化胜率。官方素材缺失时显示明确占位，不使用生成图或近似图。

## 本地开发

```bash
npm install
npm run dev
```

GitHub Pages 静态构建：

```bash
npm run build:pages
```

站点同时兼容 GitHub Pages 子路径 `/haidou-assistant/` 与后续 Nginx 根路径部署。

## 发布流程

所有功能在 `feat/*` 分支开发，经 Draft PR 提供预览、数据差异与兼容性结果。只有在测试人明确回复“测试通过，可以合并”后才合并到 `main`；合并采用 squash，并同步更新 [CHANGELOG.md](./CHANGELOG.md)。
