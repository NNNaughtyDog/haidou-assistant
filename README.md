# 海斗助手

面向微信内置浏览器的《英雄联盟》端游“海克斯大乱斗”手机决策工具。

当前开发版本：`v0.2.1`（补丁 `16.16.1 / 16.16`）

## 功能

- 173 位英雄的官方简体中文目录、头像与原画
- 国服 172 位英雄与全球 171 位英雄统计分开展示；缺失值不推测
- 国服展示胜率、选取率、样本场次和强度排名
- 接入当前版本完整 208 个强化；记录已选强化，只在当前英雄已观察到的固定强化池内计算下一张强化
- 录入本轮三选一并比较；池外强化不会进入候选区
- 根据英雄与强化联动调整装备顺序
- 本机收藏、对局状态持久化与微信系统分享
- 每个数据区均可查看来源、补丁、样本与更新时间

## 数据口径

- 英雄与装备目录、图标：Riot Data Dragon `16.16.1`
- 英雄强度（全球）：ARAM Mayhem `26.16`
- 英雄强度（国服）：Hexdata `16.16` 艾欧尼亚活跃玩家冻结样本（172 位）
- 英雄×强化池、搭配胜率与样本：Hexdata `16.16` 同一冻结快照
- 208 个强化的名称、描述、统计与图标：Hexdata / CommunityDragon `16.16` 客户端提取素材

“搭配率”表示该强化在英雄对局样本中的出现比例，不等于系统发牌概率。无法在当前版本目录中核验的强化直接移除，不生成伪官方条目。

刷新国服数据快照：

```bash
npm run data:sync
```

## 本地开发

```bash
npm install
npm run dev
```

GitHub Pages 静态构建：

```bash
npm run build:pages
```

站点同时兼容 GitHub Pages 子路径 `/haidou-assistant/` 与后续 Nginx 根路径部署。

生产域名：`https://hex.aicollie.cn/`（腾讯云首尔轻量应用服务器）。部署由
`.github/workflows/deploy-tencent.yml` 完成，SSH 私钥仅从 GitHub Actions Secret
`SEOUL_SSH_KEY` 读取。

## 发布流程

所有功能在 `feat/*` 分支开发，经 Draft PR 提供预览、数据差异与兼容性结果。只有在测试人明确回复“测试通过，可以合并”后才合并到 `main`；合并采用 squash，并同步更新 [CHANGELOG.md](./CHANGELOG.md)。
