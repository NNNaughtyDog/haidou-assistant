# 海斗实验室

白天可以直接玩原创构筑乱斗，晚上可以作为《英雄联盟》端游“海克斯大乱斗”手机决策工具。

当前开发版本：`v0.4.0`（实战数据补丁 `16.16.1 / 16.16`）

## 功能

- 原创构筑乱斗：每日角色三选一、24个原创强化、有限刷新、六轮自动战斗与Boss结算
- 不需要录入任何信息即可完成一局，单局目标时长3～5分钟
- 本地保存累计挑战、通关、最高分和强化图鉴进度
- 双模式导航：`玩一局 / 实战助手 / 图鉴 / 我的`
- 173 位英雄的官方简体中文目录、头像与原画
- 国服 172 位英雄与全球 171 位英雄统计分开展示；缺失值不推测
- 国服展示胜率、选取率、样本场次和强度排名
- 接入当前版本完整 208 个强化；记录已选强化，只在当前英雄已观察到的固定强化池内计算下一张强化
- 录入本轮三选一并比较；池外强化不会进入候选区
- 根据英雄与强化联动调整装备顺序
- 本机收藏、对局状态持久化与微信系统分享
- 每个数据区均可查看来源、补丁、样本与更新时间

## 数据口径

- 英雄与装备目录、图标：Riot Data Dragon `16.16.1`
- 国服英雄排名、胜率与选取率：ARAMGG（腾讯国服公开统计汇总）
- 强化梯度：ARAMGG；强化图片：CommunityDragon `16.16`
- 遵守 Riot 政策：不展示强化胜率，强化建议仅提供机制梯度和 0–100 匹配分
- 英雄强度（全球）：ARAM Mayhem `26.16`
- 英雄固定强化池：Hexdata `16.16` 同一冻结快照，仅用于过滤可出现的候选
- 208 个强化的名称、描述与图标：Hexdata / CommunityDragon `16.16` 客户端提取素材

强化匹配分不是胜率或系统发牌概率。无法在当前版本目录中核验的强化直接移除，不生成伪官方条目。

刷新国服数据快照：

```bash
npm run data:sync
```

## 本地开发

```bash
npm install
npm run dev
```

GitHub Pages 静态构建：

```bash
npm run build:pages
```

站点同时兼容 GitHub Pages 子路径 `/haidou-assistant/` 与后续 Nginx 根路径部署。

生产域名：`https://hex.aicollie.cn/`（腾讯云首尔轻量应用服务器）。部署由
`.github/workflows/deploy-tencent.yml` 完成，SSH 私钥仅从 GitHub Actions Secret
`SEOUL_SSH_KEY` 读取。

## 发布流程

功能开发仍通过 `feat/*` 分支评审；日常游戏数据更新则由定时任务在完整抓取、漂移校验、构建和回归测试通过后直接更新 `main`，并自动部署腾讯云。任何环节失败都会停止发布、保留上一份可靠版本，并创建 GitHub Issue 提醒。
