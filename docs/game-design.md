# 构筑乱斗：产品与玩法策划

状态：`MVP 已实现`  
目标平台：手机网页，重点覆盖 320–430px、Android 16、微信 8.x 和移动 Chrome。

## 1. 产品定位

同一个网站包含两种互补体验：

- **玩一局**：白天没有时间打开端游时，3～5分钟完成一次原创构筑肉鸽。
- **实战助手**：晚上玩海克斯大乱斗时，查询英雄、强化固定池和联动出装。

小游戏不是问答题库，也不要求用户填写对局状态。系统自动给出角色、强化和对手，玩家只做高影响选择。

## 2. 核心心理循环

1. 三选一降低理解门槛。
2. 有限刷新制造“现在拿还是再赌一次”的张力。
3. 重复标签让普通强化组合后发生质变。
4. 棱彩强化和负面代价强化制造天胡与豪赌体验。
5. 战力、生命、天胡指数和战斗结果持续提供力量反馈。
6. 一局六轮，失败后可以立即重开。
7. 每日固定种子让所有玩家面对相同开局，便于比较和分享。

## 3. MVP流程

```text
每日三角色选一
  → 三强化选一 / 可有限刷新
  → 自动战斗结算
  → 重复六轮
  → Boss与总分结算
  → 分享构筑 / 再来一局
```

当前内容量：

- 6个原创角色，其中每日展示3个。
- 24个原创强化，分白银、黄金、棱彩。
- 6名逐步增强的敌人。
- 15个构筑标签：远程、近战、连击、暴击、技能、回响、爆发、护盾、反击、续航、位移、斩杀、成长、召唤等。

## 4. 数值模型

```text
基础值 = 攻击 × 1.35 + 防御 × 0.72 + 暴击 × 0.45
协同值 = 每个重复标签从第2层开始获得8点
最终战力 = (基础值 + 协同值 + 角色特性) × 强化倍率
```

对手每轮拥有固定基础战力，并通过每日种子产生小幅波动。选择同一角色和同一强化序列时，结果可复现。

## 5. 助手与小游戏共用能力

- 实战助手使用国服英雄、强化固定池和当前模式装备数据。
- 小游戏使用原创角色、强化、敌人和战斗结算。
- 两种模式共用标签与构筑思维，未来可共用稳健、豪赌、爆发、续航等偏好画像。
- 小游戏不伪装成端游模拟器，不直接复刻英雄、技能或客户端战斗。

## 6. 后续迭代

### v0.5：强化构筑质变

- 三层标签触发专属进化文案和特效。
- 任务型强化拥有多阶段进度。
- 加入锻造器和风险事件，打破纯强化选择节奏。
- 增加暴击、护盾、治疗和斩杀反馈动画。

### v0.6：增加重复游玩目标

- 构筑图鉴与角色流派完成度。
- 每日挑战分享卡。
- 本地成就与最高伤害记录。
- 异步“挑战好友构筑”，不做实时PVP。

### v0.7：改善实战桥接

- 恢复并完善PC端自动识别。
- 手机拍摄屏幕识别作为增强入口。
- 根据小游戏中的流派偏好调整助手展示顺序，同时保留客观数据口径。

## 7. 成功指标

- 首次打开到做出第一个选择不超过10秒。
- 一局中无文本输入操作。
- 单局平均时长3～5分钟。
- 完成一局后主动再开一局的比例。
- 白天小游戏用户转入实战助手的比例。
