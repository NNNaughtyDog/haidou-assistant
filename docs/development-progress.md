## 发布原则

1. 功能开发进入 `feat/*` 分支并创建Draft PR。
2. 用户真机测试通过后再合并到 `main`。
3. `main`自动构建并部署到 `https://hex.aicollie.cn/`。
4. 构建、DNS或线上校验失败时停止发布并保留旧版本。
5. 游戏数据自动更新与小游戏原创数据分开维护，避免自动抓取覆盖原创玩法配置。
