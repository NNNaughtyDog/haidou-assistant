# v0.2.0 移动端验收清单

目标真机：小米 15 / Android 16 / 微信 8.x。

## 主流程

1. 微信内打开预览地址，确认首屏英雄原画与头像正常显示。
2. 点击当前英雄，搜索并选择任意英雄。
3. 在国服与全球之间切换，确认缺失数据不会显示为 0。
4. 添加两个已选强化，确认“下一张值得等”顺序变化。
5. 录入三个候选，确认首选置顶且匹配分标注清楚。
6. 添加与移除装备，刷新后确认本局状态保留。
7. 点击分享，确认微信调起分享或复制链接。
8. 打开数据说明，确认每个来源链接、补丁和更新时间可见。

## 兼容性

- 320px、360px、390px、430px 宽度无横向滚动。
- 横屏下底部面板可滚动，关闭按钮可见。
- 系统字体放大 125% 与 150% 时重要内容不截断。
- 刘海与底部手势区不遮挡顶部和底部导航。
- 无悬停依赖；所有按钮触控区至少 44px。
- 素材加载失败时显示“素材缺失”，不出现字母头像或破图标记。
